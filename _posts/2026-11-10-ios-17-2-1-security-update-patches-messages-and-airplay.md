Apple released iOS 27.2.1 for iPhone alongside a variety of related software updates on other platforms. The update includes bug fixes and security updates addressing vulnerabilities in Messages, AirPlay, Bluetooth, and more.

## Why it matters

In Messages, a remote attacker could have potentially been able to join an iMessage group chat uninvited. With AirPlay, an attacker in Bluetooth range might have been able to bypass the rate limit on pairing code attempts. These security updates help protect users from unauthorized access and potential remote exploits.

## The key fact

In Messages, a remote attacker could have potentially been able to join an iMessage group chat uninvited.

## Context

Apple published security notes detailing the fixes included in the new software updates because many of the fixes are identical across different platforms due to shared code.
