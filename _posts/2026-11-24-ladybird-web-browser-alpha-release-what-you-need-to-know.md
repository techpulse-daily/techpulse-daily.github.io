The Ladybird web browser has reached the alpha stage. It is now available for download on macOS and Linux.

## Why it matters

Web developers can test their websites in Ladybird to find what breaks. The browser supports WebDriver for automated testing and the Firefox DevTools protocol. Users can report broken sites from inside the browser and choose whether to send crash reports.

## The key fact

The browser features its own engine built from the ground up, rather than being a fork.

## Context

Until now, users had to build Ladybird from source to see how quickly it improves.
