Software engineer and engineering manager Giorgi Kobaidze published an article analyzing the difference between vibe coding and software engineering. The piece examines the role of human code review and sparked debate among developers regarding what constitutes engineering versus assembly.

## Why it matters

Relying purely on vibe coding without reviewing or understanding generated code poses severe risks for financial systems, health apps, and software handling sensitive data. Professional engineering requires evaluating security, edge cases, maintenance, and system failure modes rather than blindly accepting AI output. Developers must balance using AI for development speed with the disciplined oversight needed to ensure product quality and user safety.

## The key fact

Kobaidze defines vibe coding as writing a prompt and handing it to an AI without editing or reviewing the resulting code, warning that doing this for products handling personal data and money shows a refusal to 'spend two to four weeks learning the absolute basics of coding, security, and best practices.'

## Context

As AI code generation advances from machine-assisted drafting toward conversational prompting, developers are increasingly debating whether prompting AI without reviewing the underlying code qualifies as legitimate engineering.
